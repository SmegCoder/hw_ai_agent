# Демонстрация исправления кода

## Сценарий

`demo` создаёт отдельную папку с ошибочным `order.py` и шестью защищёнными
unittest-тестами. Ошибка касается расчёта скидки и проверки диапазона 0–100.
Модель получает задачу, изучает файлы, исправляет модуль и запускает тесты.
Программа независимо повторяет проверку и сравнивает SHA-256 тестового файла.

```bash
hw-ai-agent doctor --provider openrouter
hw-ai-agent demo --provider openrouter --mode safe
hw-ai-agent demo --provider openrouter --mode auto
```

Установка и настройки — в [README](../README.md). Модель берётся из `.env`
или `--model ID`; доступные провайдеры — OpenRouter, OpenAI, Ollama.
Каждая команда создаёт новый workspace. Это реальные обращения к модели,
у `demo` нет флага `--offline`.

В Safe подтвердите каждую запись и Bash. В Auto они выполняются после проверок
без вопросов; удаление всегда требует отдельного подтверждения. Узкий профиль:

```bash
hw-ai-agent demo --provider openrouter --mode auto --policy policies/demo.json
```

## Результат

Успех обозначается `DEMO PASS`, кодом 0 и полями `tests_unchanged=true`,
`model_ran_passing_tests=true` в `demo-report.json`. Финальный текст модели
не заменяет проверку. Заказ `[100, 50]` со скидкой 10% должен стоить 135.
Отчёт содержит события, diff, модель, usage, расход и ID сессии.

## Сохранённый пример

[deepseek-demo-report.json](deepseek-demo-report.json) — успешный запуск
`deepseek/deepseek-v3.2` через OpenRouter на предыдущей версии.
Модель нашла и прочитала оба файла, исправила формулу и валидацию, сама
запустила шесть тестов. Независимая проверка прошла, тестовый файл неизменён.

В отчёте зафиксированы пять обращений и сумма `usage.cost` $0.0011692656.
Это расход конкретной сохранённой сессии, а не актуальный тариф или обещанная
цена следующего запуска. JSON служит примером результата и не подтверждает
все возможности текущей версии.

## Воспроизводимая проверка

```bash
REQUIRE_SANDBOX_TESTS=1 python -m unittest discover -s tests -v
```

Тесты проверяют клиент и механизм демо подставными ответами, а инструменты —
в том числе настоящей системной песочницей macOS. Они не оценивают качество
модели. Продолжение сессии описано в [SESSION_RESULTS.md](SESSION_RESULTS.md),
ограничения инструментов — в [POLICY_RESULTS.md](POLICY_RESULTS.md).
