## Воспроизведение текущего демо

Установите проект по [README](../README.md), настройте модель и ключ в `.env`.
Если файл уже настроен, повторный `setup` не нужен. Из корня проекта:

```bash
hw-ai-agent doctor --provider openrouter
hw-ai-agent demo --provider openrouter --mode safe
hw-ai-agent demo --provider openrouter --mode auto
```

Это настоящие обращения к API. В Safe подтверждайте каждую запись и Bash.
В Auto они выполняются сразу после проверок. Удаление в обоих режимах
подтверждается отдельно. Каждая команда создаёт новую папку `workspace/demo-*`.

Успех: `DEMO PASS`, код 0, `tests_unchanged=true` и
`model_ran_passing_tests=true` в `demo-report.json`. Программа проверяет результат
независимо от финального ответа модели. Персональные пути в отчёте очищаются,
но произвольный текст не очищается от секретов: перед публикацией просмотрите его.

## Проверка runtime

```bash
REQUIRE_SANDBOX_TESTS=1 python -m unittest discover -s tests -v
```

Текущий полный набор: 245 тест без ошибок и пропусков. Запуски API в этих
тестах подставные; инструменты и системная песочница проверяются отдельно.
Для Bash требуется macOS с `sandbox-exec`; небезопасного запасного режима нет.
Прямой OpenAI проверен подставными HTTP-ответами. Историческое успешное
продолжение локальной Ollama описано в [SESSION_RESULTS.md](SESSION_RESULTS.md).
