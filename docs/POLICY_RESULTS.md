# Policy и подтверждения: проверка

## Текущее поведение

| Действие | Safe | Auto |
|---|---|---|
| Чтение и список файлов | Сразу, если разрешено policy | Сразу, если разрешено policy |
| Запись | Подтверждение каждого вызова | Сразу после проверок |
| Bash | Подтверждение каждого вызова | Сразу после проверок |
| Удаление | Подтверждение каждого вызова | Подтверждение каждого вызова |

Каждый вызов проходит `ToolRuntime.execute`: проверку аргументов, путей,
команды, директорий и policy. Явный запрет имеет приоритет. Подтверждение не
отменяет запрет, защиту тестов и секретов или ограничения системной песочницы.
В Auto запись и Bash не требуют первого подтверждения или разрешения на сессию.

Конфигурации находятся в [policies](../policies/demo.json), вне workspace:
`demo`, `review`, `readonly`. `directories.allow` и `directories.deny`
ограничивают каталоги и их потомков. `rules` сопоставляет канонический путь
или полную команду; `defaults` задаёт решение, если правило не совпало.

Перед записью в Safe показывается diff, перед удалением — файл и размер.
Состояние сохраняется до вопроса. Если ответа ещё нет, `resume` снова запросит
подтверждение. Отказ возвращается модели как ошибка инструмента.

## Воспроизводимые проверки

```bash
hw-ai-agent policy-demo
REQUIRE_SANDBOX_TESTS=1 python -m unittest discover -s tests -v
```

Ожидаемый итог автономного демо: `POLICY DEMO PASS`. Оно использует подставные
ответы оператора и не обращается к модели. Полный набор: 323 теста.

Проверены разрешения, отказы, приоритет запрета, полная команда Bash, запрещённые
директории, выход через `..` и симлинки, защита тестов и секретов, подмена цели
перед записью и удалением. Чтение через проверенные дескрипторы не следует за
подменённым файлом или родительским каталогом; жёсткие ссылки отклоняются.
Проверка SHA-256 обнаруживает правку содержимого даже при восстановленном mtime,
а служебное изменение ctime в macOS не вызывает ложный конфликт.

Дочернему процессу Bash запрещены запись файлов workspace и сеть. Ограничения
чтения policy применяются внутри процесса. Для Bash поддерживаются точные пути
и шаблоны `*`/`?`; неподдерживаемое ограничение с `[]` приводит к отказу запуска.
Тесты с файловыми побочными эффектами, включая временные файлы, не поддерживаются.

## Исторический запуск с настоящей моделью

[policy-deepseek-demo-report.json](policy-deepseek-demo-report.json) содержит
успешный `DEMO PASS` для `deepseek/deepseek-v3.2` через OpenRouter: шесть тестов
прошли, тестовый файл не изменился, решения policy сохранены в отчёте.
Это запуск предыдущей версии, до последующего усиления файловой защиты;
он не является доказательством новых правил подтверждения.

Текущий сценарий с узким профилем:

```bash
hw-ai-agent demo --provider openrouter --mode auto --policy policies/demo.json --approvals deny
```

Профиль допускает запись только `order.py` и одну команду тестов. Модель берётся
из `.env`. Запуск обращается к API. Для ручного отказа запустите `demo --mode safe`
и ответьте `n`: файл останется неизменным, модель получит причину отказа.
Отказ от нужного исправления может привести к `DEMO FAIL` — задача не выполнена.

Полные команды: [README](../README.md), [WORKFLOW_GUIDE.md](WORKFLOW_GUIDE.md).
