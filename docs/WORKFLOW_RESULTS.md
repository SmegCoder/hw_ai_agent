# Архив раннего многофайлового демо

> Этот документ описывает сохранённый запуск предыдущей версии.
> Текущие режимы и команды: [WORKFLOW_GUIDE.md](WORKFLOW_GUIDE.md).

[workflow-safe-report.json](workflow-safe-report.json) содержит успешный
детерминированный сценарий: исправлены `tax.py` и `receipt.py`, два теста прошли,
тестовый файл не изменён. Во время запуска была пауза после сохранённого
результата, затем продолжение той же сессии. Итог — `WORKFLOW DEMO PASS`.

В той версии Safe запоминал отдельные разрешения на инструменты внутри сессии:
один вопрос записи и один вопрос Bash. **Это прежнее поведение.** Сейчас Safe
подтверждает каждую запись и Bash, а оба режима подтверждают каждое удаление.
Текущий маленький offline-сценарий требует четыре подтверждения в Safe и
не требует вопросов записи и Bash в Auto. Команды старой версии здесь не
приводятся, чтобы архив нельзя было принять за текущую инструкцию.

В сохранённом JSON пути очищены. Подставная модель проверяет механизм runtime;
такой результат не доказывает способность настоящей модели выбрать действия.

Расширенное демо сейчас по умолчанию использует настоящую модель и восемь
исходных файлов. Исторический [workflow-ollama-partial-report.json](workflow-ollama-partial-report.json)
показывает функциональный успех с `qwen3:4b-instruct`, но без очистки:
`functional_success=true`, `cleanup_complete=false`, `success=false`.
Этот результат честно сохранён как неполный успех сценария.
